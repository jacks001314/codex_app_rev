# chatgpt-surfaces

ChatGPT 侧的页面与组件。502 个 chunk，原始 6,119,457 B。

内容覆盖 `chatgpt-*` 前缀的首页、会话内容、GPTs / agent directory、共享、
通知、moderation、memory、apps、widgets、work / students 等。它同时被本地
Codex 会话、Quick Chat 与 ChatGPT Work 复用。

阅读建议：先看 `_CATALOG.json` 中的 `chatgptConversations.*`、`chatgpt.settings.*`、
`chatgpt.work.*`、`chatgpt.tpp.*` 组的 `description`，再按需打开具体 chunk。
